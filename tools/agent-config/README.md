# agent-config

Generates `AGENTS.md` (read by Codex and other agent harnesses) from `CLAUDE.md` (read by Claude Code), and links skills.
Python 3.9+, standard library only.

## Profiles
- Project: `python3 -I agent_config.py --root DIR` writes `DIR/AGENTS.md` from `DIR/CLAUDE.md`. Optional config:
  `DIR/.claude/agent-config.json`. Skill links go to `DIR/.agents/skills/`.
- Global: `python3 -I agent_config.py --global` writes `~/.codex/AGENTS.md` from `~/.claude/CLAUDE.md`. Config:
  `global.json` next to this tool. Needs an existing `~/.codex`. Skill links go to `~/.agents/skills/`.
- `--check` reports drift and never writes.

Output = marker line + source with the configured rewrites applied + a fixed closing section that says Claude Code's
hooks and permission rules do not run under other harnesses. Project output of 32 768 bytes or more is refused.

## Config
```json
{
  "rewrites": [
    {"find": "A hook (`guard.sh`) stops this edit.",
     "replace": "Under Claude Code a hook stops this edit. Elsewhere nothing enforces it, so apply it yourself."}
  ],
  "skills": ["demo"]
}
```
Only the keys `rewrites` and `skills` are allowed. Each `find` must occur exactly once in the source.
`skills` names are unique and match `[A-Za-z0-9_][A-Za-z0-9_.-]*`.

## Claim sweep
After the rewrites are cut out, any source line that looks like a claim that a hook enforces a rule stops the run.
A claim line contains `.claude/hooks/`, `PreToolUse`, a word like `name-guard` or `name-guard.sh`, or the word
`hook`/`hooks` together with a word starting `refus`, `block`, `den`, `reject` or `enforc`.
To answer a failure, add a rewrite for that sentence. A rewrite whose `find` equals its `replace` records
"reviewed, true under every harness".

## Exit codes
0 up to date or written. 1 drift (`--check` only). 2 invalid source or config, refusal, or usage error.

## Marker and refusals
Line 1 of every output is `<!-- GENERATED by agent_config.py from ... -->`. A file is managed only if it is a regular
file (not a symlink) starting with that marker. Exit 2 and nothing written when: an existing `AGENTS.md` is not
managed; `AGENTS.override.md` sits next to the output; an output directory is a symlink; an unmanaged entry sits at a
listed skill name; `--global` runs with `CODEX_HOME` set elsewhere or without `~/.codex`.

## Skills
Each listed skill becomes a relative symlink `<skills_out>/<name>` -> `../../.claude/skills/<name>`. The skill needs a
`SKILL.md` with frontmatter and a non-empty `description`. Managed links that are no longer listed are removed.
Unmanaged entries are never touched.

## Vendoring
The code repo carries a byte-identical copy of this directory's three files (`agent_config.py`,
`test_agent_config.py`, `README.md`). Change both.
