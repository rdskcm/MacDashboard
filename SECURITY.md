# Security Policy

## Supported versions

This is a solo, source-only project — only the latest release is supported.
If you're on an older build, please update before reporting.

## Reporting a vulnerability

Please report security issues privately, not as a public GitHub issue: use
GitHub's Private Vulnerability Reporting (Security tab → "Report a
vulnerability"), or go directly to
[https://github.com/rdskcm/MacDashboard/security/advisories/new](https://github.com/rdskcm/MacDashboard/security/advisories/new).

**Please don't include your own `mac_report.txt` or other diagnostic report
files in the report.** That file is machine-identifying (folder names,
installed-app hints, process names, Time Machine destination name — see the
Privacy section in README.md) and there's essentially never a need to
include the whole thing to describe a security issue; a short description
and, if relevant, a redacted excerpt is enough.

## What to expect

I'm not a company and there's no bug bounty — this is a hobby project I
build and maintain on my own. I'll do my best to respond and fix things
promptly, but I can't promise a specific response time. Thanks for taking
the time to report responsibly instead of filing publicly.
